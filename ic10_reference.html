IC10 MIPS Architecture & Opcode Specification

Complete instruction set reference for the programmable IC10 microprocessor chip in Stationeers. Hardware limits: 128 lines of code (0–127), 16 general-purpose registers (r0–r15), and 6 peripheral device channels (d0–d5, plus db).

Sending Commands to Devices Example (Autolathe / Printer)

Control specialized machines by bit-packing recipes and writing to address 0 of their stack: 

# Aliases for clarity
alias Printer d0
alias Command r0
alias ItemQuantity r1
alias ItemHash r2

# Build recipe payload
move ItemQuantity 1
move ItemHash HASH("ItemKitPipe")

move Command PrinterInstruction.ExecuteRecipe
ins Command 8 8 ItemQuantity
ins Command 16 32 ItemHash

# Dispatch to machine stack
clr Printer
put Printer 0 Command

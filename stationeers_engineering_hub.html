📐 IC10 Technical Architecture & Hardware Limits

MIPS Standards & Mechanics

⚡ 0.5s Gametick Loop

Always include yield or sleep X in the main execution loop to prevent CPU halts and maintain tick synchronization.

📏 Hardware Boundaries

Strict limit of 128 code lines (0–127), 16 registers (r0–r15), and 6 device pins (d0–d5 plus db).

🏷️ Hashing & Batch Control

Utilize sbn and lbn with dual deviceHash and nameHash targeting to operate multiple devices without dedicating screw pins.

🌡️ Standard SI Units

Temperature is measured strictly in Kelvin (K = °C + 273.15). Pressure is measured in kilopascals (kPa).

2. De Code

# ========================================================
# Stationeers IC10: Habitat Atmosphere & Telemetry Link
# ========================================================

# Aliases voor hardware pennen
alias Sensor d0
alias DisplayPres d1
alias DisplayTemp d2

# Aliases voor registers
alias Pres r0
alias Temp r1
alias Pollutant r2
alias StatusColor r3
alias IsDanger r4
alias IsWarning r5

# Constanten voor comfort- en gevaargrenzen
define MinPres 80.0       # Ondergrens veilige druk in kPa
define MaxPres 120.0      # Bovengrens veilige druk in kPa
define MinTemp 288.15     # Ondergrens temperatuur (15 C in Kelvin)
define MaxTemp 303.15     # Bovengrens temperatuur (30 C in Kelvin)

# Paint+ en IC10 Color identifiers
define ColorSafe 2        # Groen (Nominaal)
define ColorWarning 5     # Geel / Amber (Waarschuwing)
define ColorDanger 4      # Rood (Kritiek)

# Batch hashes voor zaalverlichting
define LightType HASH("StructureWallLight")
define LightName HASH("Hallway Light Wall")

main:
    # Synchroniseer met de 0.5s gametick cyclus
    yield

    # 1. Lees omgevingsdata uit via de gassensor
    l Pres Sensor Pressure
    l Temp Sensor Temperature
    l Pollutant Sensor PollutantRatio

    # 2. Update de modulaire displaypanelen
    s DisplayPres Setting Pres
    s DisplayTemp Setting Temp

    # 3. Controleer op gevaar: vacuüm (< 40 kPa) of toxisch gas (> 1%)
    slt IsDanger Pres 40.0
    bgt Pollutant 0.01 setDanger
    bnez IsDanger setDanger

    # 4. Controleer op waarschuwing: temperatuur of druk buiten bereik
    slt IsWarning Pres MinPres
    bgt Pres MaxPres setWarning
    slt r6 Temp MinTemp
    or IsWarning IsWarning r6
    bgt Temp MaxTemp setWarning
    bnez IsWarning setWarning

    # 5. Geen afwijkingen gedetecteerd: status is veilig
    move StatusColor ColorSafe
    j applyStatus

setDanger:
    move StatusColor ColorDanger
    j applyStatus

setWarning:
    move StatusColor ColorWarning

applyStatus:
    # 6. Schrijf de berekende kleur weg naar de zaalverlichting via batch-instructie
    sbn LightType LightName Color StatusColor

    # Herhaal routine
    j main

3. Korte Uitleg & Afstelling

Dit script leest elke tick van 0.5s de druk, temperatuur en het percentage vervuiling uit via sensor d0 en toont dit op meters d1 en d2. Bij vacuüm, overdruk of giftige gassen kleurt alle gekoppelde verlichting via sbn direct rood of geel. De drempelwaardes pas je naar wens aan via MinPres (80 kPa), MaxPres (120 kPa), MinTemp (288.15 K) en MaxTemp (303.15 K).

2. De Code

# ========================================================
# Stationeers IC10: Pipe Element Identifier & Status Link
# ========================================================

# Aliases voor hardware pennen
alias Analyzer d0
alias Display d1

# Aliases voor registers
alias Temp r0
alias TotalMoles r1
alias Oxygen r2
alias Volatiles r3
alias Pollutant r4
alias TargetColor r5

# Logische kleurcodes conform Stationeers standaard
define ColorTeal 10     # Zuurstof / Koud
define ColorOrange 5    # Volatiles / Brandstof
define ColorGreen 2     # Veilig / Neutraal
define ColorRed 4       # Gevaar / Toxisch

# Batch targeting voor leiding-statuslampen
define LightType HASH("StructureWallLight")
define LightName HASH("Pipe Status Light")

main:
    # 0.5s tick synchronisatie en CPU-ontlasting
    yield

    # 1. Lees leidingcondities uit
    l Temp Analyzer Temperature
    l TotalMoles Analyzer TotalMoles
    l Oxygen Analyzer RatioOxygen
    l Volatiles Analyzer RatioVolatiles
    l Pollutant Analyzer RatioPollutant

    # 2. Toon leidingtemperatuur direct op het display (in Kelvin)
    s Display Setting Temp

    # 3. Bepaal dominante inhoud voor netwerk-alarmering
    bgt Volatiles 0.10 setVolatiles
    bgt Pollutant 0.05 setPollutant
    bgt Oxygen 0.50 setOxygen

    # Standaard neutrale veilige status
    move TargetColor ColorGreen
    j updateLights

setVolatiles:
    move TargetColor ColorOrange
    j updateLights

setPollutant:
    move TargetColor ColorRed
    j updateLights

setOxygen:
    move TargetColor ColorTeal

updateLights:
    # 4. Update wandindicatielampen in batchmodus via type en naam
    sbn LightType LightName Color TargetColor

    # Herhaal cyclus
    j main

3. Korte Uitleg & Afstelling

Dit script monitort de moleculaire compositie van een leiding via de Pipe Analyzer op d0 en toont de temperatuur op d1. Bij aanwezigheid van brandbare Volatiles (>10%), toxische stoffen (>5%) of pure zuurstof schakelen de leidingindicatoren direct om naar hun herkenbare Paint+ signaalkleur. Pas de drempelpercentages aan in de bgt-instructies voor fijnmazigere procesregeling.

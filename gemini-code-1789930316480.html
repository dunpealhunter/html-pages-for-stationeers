Stationeers Hardware & Slot Matrix

Interne IC10 Behuizing & Netwerk Aansluitingen

In Stationeers heeft elke IC10 chip 6 fysieke schroefpinnen (d0 t/m d5). De behuizing zelf kan worden aangesproken via db.

Pin IdentifierIn-game TypeToepassing in Complex
d0Schroefpin 0Primaire actuator (Airlock Door, Filtration Unit, Primary Vent)
d1Schroefpin 1Secundaire actuator (Blast Door, Gas Storage Tank, Extract Vent)
d2Schroefpin 2Primaire Sensor (Gas Sensor, Pipe Analyzer In)
d3Schroefpin 3Secundaire Sensor (Sluis Sensor, Pipe Analyzer Out, Occupancy Sensor)
d4Schroefpin 4Shared Communication (Logic Memory Hazard Bus, Interlock Sync)
d5Schroefpin 5Telemetrie Export / Display Memory voor Modular Consoles Reloaded
dbDevice BaseInterne IC Housing / Geïntegreerde stack & statusled

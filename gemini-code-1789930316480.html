Energiebeheer & Element Filtratie Telemetrie

1. Power Monitor voor Modular Consoles

Dataruimte - Wand 4
36 Regels

Pentoewijzing (Pin Configuration)

PinApparaatFunctie
d0MemTotalChargeLogic Memory - Totaal opgeslagen lading in Joules.
d1MemDeltaWattLogic Memory - Actueel netto vermogen in Watt (Delta/sec).
d2MemAvgWattLogic Memory - Exponentieel rollend gemiddelde (Watt).
 
# ========================================================
# IC10 - POWER MONITOR VOOR MODULAR CONSOLES
# Batch-uitlezing van accubank, watt-berekening en EMA
# ========================================================

alias MemTotalCharge d0
alias MemDeltaWatt   d1
alias MemAvgWatt     d2

define BATTERY_HASH     HASH("StructureBatteryLarge")
define TICK_DELTA_SEC   0.5
define ALPHA            0.1

alias CurrentCharge  r0
alias PrevCharge     r1
alias DeltaJoules    r2
alias InstantWatt    r3
alias AvgWatt        r4
alias Initialized    r5
alias TempReg        r6

main:
    yield
    lb CurrentCharge BATTERY_HASH Charge 1
    bnez Initialized calc_power
    move PrevCharge CurrentCharge
    move AvgWatt 0
    move Initialized 1
    j store_data

calc_power:
    sub DeltaJoules CurrentCharge PrevCharge
    div InstantWatt DeltaJoules TICK_DELTA_SEC
    sub TempReg InstantWatt AvgWatt
    mul TempReg TempReg ALPHA
    add AvgWatt AvgWatt TempReg
    move PrevCharge CurrentCharge

store_data:
    s MemTotalCharge Setting CurrentCharge
    s MemDeltaWatt Setting InstantWatt
    s MemAvgWatt Setting AvgWatt
    j main
Korte Uitleg: Leest via batch-uitlezing (lb) alle grote batterijen tegelijk uit en stuurt live lading, actueel vermogen en een afgevlakt gemiddelde naar drie Logic Memory chips voor weergave op Modular Consoles schermen.

2. Element Filtratie & Leiding Telemetrie Controller

Filtratiekamer - Wand 3
44 Regels

Pentoewijzing (Pin Configuration)

PinApparaatFunctie
d0FiltrationDe actieve gasfiltratie-eenheid voor het element.
d1StorageTankGrote opslagtank voor het gefilterde element.
d2PipeInPipe Analyzer op de vuile toevoerleiding.
d3PipeOutPipe Analyzer op de leiding naar de opslagtank.
d4MemTankLogic Memory - Exporteert tankdruk (kPa) naar consoles.
d5MemFilterLogic Memory - Exporteert filterconditie (%) naar consoles.
 
# ========================================================
# IC10 - FILTRATIE & LEIDING TELEMETRIE CONTROLLER
# Procesregeling, filterbewaking en batch-alarmering
# ========================================================

alias Filtration    d0
alias StorageTank   d1
alias PipeIn        d2
alias PipeOut       d3
alias MemTank       d4
alias MemFilter     d5

define MIN_IN_PRESS       20.0
define MAX_PIPE_PRESS     50000.0
define MAX_TANK_PRESS     55000.0
define MIN_SAFE_TEMP      200.0
define MAX_SAFE_TEMP      350.0
define MIN_FILTER_PCT     1.0
define ALARM_LIGHT_HASH   HASH("StructureFlashingLight")

alias InPress       r0
alias OutPress      r1
alias TankPress     r2
alias OutTemp       r3
alias Filter0       r4
alias Filter1       r5
alias MinFilter     r6
alias FaultFlag     r7
alias RunState      r8

main:
    yield
    l InPress   PipeIn Pressure
    l OutPress  PipeOut Pressure
    l TankPress StorageTank Pressure
    l OutTemp   PipeOut Temperature

    ls Filter0 Filtration 0 Quantity
    ls Filter1 Filtration 1 Quantity
    min MinFilter Filter0 Filter1

    sgt r9 OutPress MAX_PIPE_PRESS
    sgt r10 TankPress MAX_TANK_PRESS
    or FaultFlag r9 r10

    slt r9 OutTemp MIN_SAFE_TEMP
    sgt r10 OutTemp MAX_SAFE_TEMP
    or r9 r9 r10
    or FaultFlag FaultFlag r9

    sgt r9 InPress MIN_IN_PRESS
    slt r10 TankPress MAX_TANK_PRESS
    and RunState r9 r10

    sgt r9 MinFilter MIN_FILTER_PCT
    and RunState RunState r9

    select RunState FaultFlag 0 RunState
    s Filtration On RunState

    sb ALARM_LIGHT_HASH On FaultFlag
    s MemTank Setting TankPress
    s MemFilter Setting MinFilter
    j main
Korte Uitleg: Bewaakt het filtratieproces en stopt de unit automatisch als de tank vol is, leidingen overbelast raken of de filterkwaliteit onder 1% zakt. Schakelt alarmlichten in via batch-sturing bij storingen.

3. Sluis 2 Containment Controller (Tussengang ↔ Filtratie)

Hallway Slot 1
54 Regels

Pentoewijzing (Pin Configuration)

PinApparaatFunctie
d0Door2AAirlock Door tussen Tussengang en Sluis 2.
d1Door2BBlast Door naar de Filtratiekamer.
d2SensorFiltGas Sensor in de Filtratiekamer.
d3SensorAir2Gas Sensor in de 2-blokken ruimte van Sluis 2.
d4OccFiltOccupancy Sensor in de Filtratiekamer.
d5MemHazardShared gevarenbus Logic Memory (1 = Alarm).
 
# ========================================================
# IC10 - SLUIS 2 & FILTRATIE CONTAINMENT CONTROLLER
# Stuurt Airlock Door 2A & Blast Door 2B aan
# Bevat noodevacuatie via Occupancy Sensor & MemHazard bus
# ========================================================

alias Door2A       d0
alias Door2B       d1
alias SensorFilt   d2
alias SensorAir2   d3
alias OccFilt      d4
alias MemHazard    d5

define MIN_SAFE_P       80.0
define MAX_SAFE_P       125.0
define MAX_SAFE_T       323.15
define MAX_TOXIC_RATIO  0.001
define MAX_CO2_RATIO    0.02

alias FiltPress    r0
alias FiltTemp     r1
alias ToxicSum     r2
alias HazardFlag   r3
alias D2AOpen      r4
alias D2BOpen      r5
alias PlayerInFilt r6
alias TempReg      r7

main:
    yield
    l FiltPress    SensorFilt Pressure
    l FiltTemp     SensorFilt Temperature
    l PlayerInFilt OccFilt Quantity

    l ToxicSum SensorFilt RatioPollutant
    l TempReg  SensorFilt RatioNitrousOxide
    add ToxicSum ToxicSum TempReg
    l TempReg  SensorFilt RatioMethane
    add ToxicSum ToxicSum TempReg
    l TempReg  SensorFilt RatioWater
    add ToxicSum ToxicSum TempReg

    slt HazardFlag FiltPress MIN_SAFE_P
    sgt TempReg FiltPress MAX_SAFE_P
    or HazardFlag HazardFlag TempReg

    sgt TempReg FiltTemp MAX_SAFE_T
    or HazardFlag HazardFlag TempReg

    sgt TempReg ToxicSum MAX_TOXIC_RATIO
    or HazardFlag HazardFlag TempReg

    l TempReg SensorFilt RatioCarbonDioxide
    sgt TempReg TempReg MAX_CO2_RATIO
    or HazardFlag HazardFlag TempReg

    l TempReg SensorAir2 RatioPollutant
    sgt TempReg TempReg MAX_TOXIC_RATIO
    or HazardFlag HazardFlag TempReg

    l D2AOpen Door2A Open
    l D2BOpen Door2B Open

    beqz HazardFlag normal_ops

    bgtz PlayerInFilt evacuate_player

    s Door2B Lock 1
    s Door2B Open 0
    s Door2A Lock 1
    s Door2A Open 0
    j update_hazard_bus

evacuate_player:
    s Door2A Lock 1
    s Door2A Open 0
    s Door2B Lock 0
    j update_hazard_bus

normal_ops:
    s Door2A Lock D2BOpen
    s Door2B Lock D2AOpen

update_hazard_bus:
    s MemHazard Setting HazardFlag
    j main
Korte Uitleg: Bewaakt de gasscheiding van Sluis 2. Schakelt bij gaslekken de MemHazard bus in en vergrendelt de deuren, behalve wanneer er een speler aanwezig is (PlayerInFilt > 0), in welk geval Blast Door 2B open blijft voor evacuatie.

4. Sluis 1 Hallway Access Controller (Hallway ↔ Tussengang)

Pentoewijzing (Pin Configuration)

PinApparaatFunctie
d0Door1ABlast Door aan de centrale Hallway-zijde.
d1Door1BAirlock Door aan de Tussengang-zijde.
d2SensorAir1Gas Sensor in Sluis 1.

# ========================================================
# IC10 - SLUIS 1 HALLWAY ACCESS CONTROLLER
# Stuurt Hallway Blast Door 1A & Airlock Door 1B aan
# Sluit de centrale gang hermetisch af bij calamiteiten
# ========================================================

alias Door1A       d0
alias Door1B       d1
alias SensorAir1   d2
alias OccAir1      d3
alias MemHazard    d4
alias MemStatus1   d5

define MAX_TOXIC_RATIO  0.001

alias HazardActive r0
alias D1AOpen      r1
alias D1BOpen      r2
alias InTransit    r3
alias ToxicCheck   r4
alias StatusVal    r5
alias TempReg      r6

main:
    yield
    l HazardActive MemHazard Setting
    l InTransit    OccAir1 Quantity
    l D1AOpen      Door1A Open
    l D1BOpen      Door1B Open

    l ToxicCheck SensorAir1 RatioPollutant
    l TempReg    SensorAir1 RatioMethane
    add ToxicCheck ToxicCheck TempReg

    beqz HazardActive check_transit

    s Door1B Lock 1
    s Door1B Open 0
    s Door1A Lock D1BOpen
    move StatusVal -1
    j write_status

check_transit:
    s Door1A Lock D1BOpen
    s Door1B Lock D1AOpen

    move StatusVal 0
    select StatusVal D1AOpen 1 StatusVal
    select StatusVal D1BOpen 2 StatusVal
    bgtz InTransit mark_occupied
    j write_status

mark_occupied:
    move StatusVal 3

write_status:
    s MemStatus1 Setting StatusVal
    j main
Korte Uitleg: Regelt de doorgang vanaf de basis. Bij een geactiveerde gevarenbus wordt Airlock Door 1B direct op slot gezet zodat giftige gassen de centrale gang niet kunnen bereiken.

d0VentExt1Powered Vent Large 1 (Mode 0: Inward / Afzuigen).
d1VentExt2Powered Vent Large 2 (Mode 0: Inward / Afzuigen).

# ========================================================
# IC10 - FILTRATIEKAMER HVAC & NOODAFZUIGING
# Bestuurt 4x Powered Vent Large (2 extractie, 2 toevoer)
# Drukbalans en geforceerde noodontluchting bij calamiteiten
# ========================================================

alias VentExt1     d0
alias VentExt2     d1
alias VentSup1     d2
alias VentSup2     d3
alias SensorFilt   d4
alias MemHazard    d5

define PRESS_MIN        100.0
define PRESS_MAX        102.0
define MAX_SAFE_T       323.15
define MAX_TOXIC_RATIO  0.001
define MODE_INWARD      0
define MODE_OUTWARD     1

alias FiltPress    r0
alias FiltTemp     r1
alias ToxicSum     r2
alias HazardActive r3
alias SupOn        r4
alias ExtOn        r5
alias TempReg      r6

main:
    yield
    l FiltPress   SensorFilt Pressure
    l FiltTemp    SensorFilt Temperature
    l HazardActive MemHazard Setting

    l ToxicSum  SensorFilt RatioPollutant
    l TempReg   SensorFilt RatioNitrousOxide
    add ToxicSum ToxicSum TempReg
    l TempReg   SensorFilt RatioMethane
    add ToxicSum ToxicSum TempReg
    l TempReg   SensorFilt RatioWater
    add ToxicSum ToxicSum TempReg

    sgt TempReg ToxicSum MAX_TOXIC_RATIO
    or HazardActive HazardActive TempReg
    sgt TempReg FiltTemp MAX_SAFE_T
    or HazardActive HazardActive TempReg

    beqz HazardActive normal_hvac

    move SupOn 0
    move ExtOn 1
    j apply_hvac

normal_hvac:
    slt SupOn FiltPress PRESS_MIN
    sgt ExtOn FiltPress PRESS_MAX

apply_hvac:
    s VentExt1 Mode MODE_INWARD
    s VentExt2 Mode MODE_INWARD
    s VentExt1 On ExtOn
    s VentExt2 On ExtOn

    s VentSup1 Mode MODE_OUTWARD
    s VentSup2 Mode MODE_OUTWARD
    s VentSup1 On SupOn
    s VentSup2 On SupOn

    j main
Korte Uitleg: Handhaaft 100–102 kPa in de filtratieruimte. Bij hitte of het vrijkomen van brandbare of giftige gassen sluiten de toevoeren en zuigen de twee grote afzuigers de kamer direct leeg.

7. Multi-Gas Toxiciteit & Ademhalingsbewaking

Algemeen / Sluizen
36 Regels

Pentoewijzing (Pin Configuration)

PinApparaatFunctie
d0SensorAtmosfeersensor van de leefruimte.
d1AlarmLightFlashing Light voor visuele waarschuwing.
d2SirenKlaxon / Akoestisch alarm.

# ========================================================
# IC10 - MULTI-GAS TOXICITEIT & ADEMHALINGSBEWAKING
# Detecteert X, N2O, Methane, Water, CO2 en O2-druk
# ========================================================

alias Sensor      d0
alias AlarmLight  d1
alias Siren       d2
alias MemStatus   d3

define MIN_O2_PP        16.0
define MAX_O2_PP        100.0
define MAX_CO2_PP       2.0
define MAX_TOXIC_RATIO  0.0005

alias TotalPress   r0
alias O2Ratio      r1
alias CO2Ratio     r2
alias O2Press      r3
alias CO2Press     r4
alias ToxicRatio   r5
alias HazardFlag   r6
alias StatusVal    r7

main:
    yield
    l TotalPress Sensor Pressure
    l O2Ratio    Sensor RatioOxygen
    l CO2Ratio   Sensor RatioCarbonDioxide

    mul O2Press  TotalPress O2Ratio
    mul CO2Press TotalPress CO2Ratio

    l ToxicRatio Sensor RatioPollutant
    l r8         Sensor RatioNitrousOxide
    add ToxicRatio ToxicRatio r8
    l r8         Sensor RatioMethane
    add ToxicRatio ToxicRatio r8
    l r8         Sensor RatioWater
    add ToxicRatio ToxicRatio r8

    sgt HazardFlag ToxicRatio MAX_TOXIC_RATIO
    select StatusVal HazardFlag 1 0

    sgt r8 CO2Press MAX_CO2_PP
    or HazardFlag HazardFlag r8
    select StatusVal r8 2 StatusVal

    slt r8 O2Press MIN_O2_PP
    sgt r9 O2Press MAX_O2_PP
    or r8 r8 r9
    or HazardFlag HazardFlag r8
    select StatusVal r8 3 StatusVal

    s AlarmLight On HazardFlag
    s Siren      On HazardFlag

    s MemStatus Setting StatusVal
    j main
Korte Uitleg: Controleert de partiële zuurstof- en CO2-druk evenals sporen van gifgas (X, N2O, Methane, waterdamp) en triggert sirens en statusconsoles bij ademhalingsgevaar.

Toepasbaar op Sluis 1, 2, 3 & Data
42 Regels

Pentoewijzing (Pin Configuration)

PinApparaatFunctie

d1VentExtractActive Vent (Mode 0: Inward / Afzuigen).
d2VentSupplyActive Vent (Mode 1: Outward / Toevoer).

# ========================================================
# IC10 - UNIVERSELE COMPARTIMENT VENTILATIE CONTROLLER
# Handhaaft 100-102 kPa en schakelt noodpurging in bij lek
# Toepasbaar op Sluis 1, 2, 3, Tussengang en Dataruimte
# ========================================================

alias SensorRoom   d0
alias VentExtract  d1
alias VentSupply   d2
alias OccSensor    d3
alias MemHazard    d4
alias MemPressure  d5

define PRESS_MIN        100.0
define PRESS_MAX        102.0
define MAX_TOXIC_RATIO  0.001
define MODE_INWARD      0
define MODE_OUTWARD     1

alias RoomPress    r0
alias RoomTemp     r1
alias ToxicSum     r2
alias HazardActive r3
alias SupOn        r4
alias ExtOn        r5
alias TempReg      r6

main:
    yield
    l RoomPress    SensorRoom Pressure
    l RoomTemp     SensorRoom Temperature
    l HazardActive MemHazard Setting

    l ToxicSum  SensorRoom RatioPollutant
    l TempReg   SensorRoom RatioNitrousOxide
    add ToxicSum ToxicSum TempReg
    l TempReg   SensorRoom RatioMethane
    add ToxicSum ToxicSum TempReg
    l TempReg   SensorRoom RatioWater
    add ToxicSum ToxicSum TempReg

    sgt TempReg ToxicSum MAX_TOXIC_RATIO
    or HazardActive HazardActive TempReg

    beqz HazardActive normal_balance

    move SupOn 0
    move ExtOn 1
    j apply_room_vents

normal_balance:
    slt SupOn RoomPress PRESS_MIN
    sgt ExtOn RoomPress PRESS_MAX

apply_room_vents:
    s VentExtract Mode MODE_INWARD
    s VentExtract On ExtOn

    s VentSupply Mode MODE_OUTWARD
    s VentSupply On SupOn

    s MemPressure Setting RoomPress
    j main
Korte Uitleg: Handhaaft autonoom 100–102 kPa in individuele ruimtes en zuigt het compartiment direct vacuüm bij gifgasdetectie of een signaal van de MemHazard bus.
